## Important: Next.js version

This project runs **Next.js 16** with **React 19**. APIs, conventions, and file structure may differ from training data. Before writing routing, data-fetching, image, or config code, check the relevant guide under `node_modules/next/dist/docs/` (`01-app/`, `02-pages/`, `03-architecture/`, `04-community/`) rather than relying on memorized Next.js patterns. Heed any deprecation notices found there.

## Commands

- `npm run dev` — start the dev server
- `npm run build` — production build
- `npm run start` — run the production build
- `npm run lint` — ESLint (flat config in `eslint.config.mjs`)
- No test suite is configured despite `@playwright/test` being a dependency — there is no `playwright.config.*` or test directory yet.

Utility scripts (run directly with `node`, not wired into `npm run`):
- `node scripts/compress-images.mjs` — compresses/converts images under `public/`
- `node scripts/gen-blur.mjs` — regenerates `src/data/blurDataUrls.json` (base64 blur placeholders keyed by image path)

## Architecture

This is the marketing/portfolio site for Studio Pensieve, a Bangalore interior design studio. App Router, `src/app/*`, path alias `@/*` → `src/*`.

**Pages**: `/`, `/about`, `/services`, `/projects`, `/projects/[slug]`, `/gallery`, `/journal`, `/contact`. Project listing/detail pages each split into a server `page.tsx` (metadata, params) and a `*Client.tsx` component holding the interactive/animated UI.

**Project data is centralized, not file-based CMS**: `src/data/projects.ts` exports a typed `Project[]` array (slug, credits, description paragraphs, an `images[]` list with `orientation`/`layout` grouping hints like `"duo" | "trio" | "quad"`, etc.). Each project's images live under `public/Projects/<Project Name>/` and are referenced via small per-project helper functions (e.g. `imgKishore`, `imgUber`) that build the encoded URL — follow this pattern when adding a new project rather than inlining paths. Blur placeholders for `next/image` come from `src/data/blurDataUrls.json` (a flat map of image path → base64 data URL), generated by `scripts/gen-blur.mjs`; regenerate it after adding/changing images.

**Page transitions and chrome are global, client-side, and GSAP-driven**, wired in `src/app/layout.tsx`:
- `TransitionProvider` (`src/components/TransitionProvider.tsx`) owns a fixed full-screen overlay and exposes `usePageTransition()` → `{ navigate, isArriving }`. Internal links should call `navigate(href, { rect, color, imageSrc })` instead of `next/link`/`router.push` directly, so the shared-element expand/fade animation plays (e.g. a clicked project card image grows to fill the viewport before the route changes).
- `MenuProvider` (`src/components/Menu.tsx`) renders the nav overlay/menu and provides menu state to descendants.
- `LoadAnimation` and `CustomCursor` are also mounted globally in the root layout (intro animation and a custom cursor respectively) and apply site-wide.

**Images**: `next.config.ts` enables AVIF/WebP, custom `deviceSizes`/`imageSizes`, and a `remotePatterns` allowlist (currently `upload.wikimedia.org`) — add new external image hosts there before using `next/image` with them.

**Fonts**: Geist is the base font; `Caveat` (Google Font, via `next/font/google`) is loaded as `--font-caveat` for accent/handwritten text. `General Sans` is loaded externally via a Fontshare `<link>` in `layout.tsx`'s `<head>`, not `next/font`.
